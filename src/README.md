# ros2_car 固件

基于 STM32H743VIT6 的四轮麦克纳姆轮小车加二轴云台控制固件。工程由 STM32CubeMX 生成，使用 FreeRTOS，通过串口与 ROS 2 主控或手动控制端通信。

配套上位机工程位于 `F:\ros2\my_robot_ws`，两端统一说明见 `F:\ros2\my_robot_ws\README.md`。

## 项目概况

| 项目 | 内容 |
| --- | --- |
| 主控 | STM32H743VIT6，LQFP100 |
| 系统时钟 | 480MHz，HCLK 240MHz，APB 120MHz |
| 实时系统 | FreeRTOS CMSIS_V2 |
| 底盘 | 四轮麦克纳姆轮，直流电机加增量编码器 |
| 云台 | 两轴步进电机，A4988 驱动，MT6701 磁编码器 |
| 姿态 | 单轴陀螺仪，串口输出偏航角和角速度 |
| 开发环境 | Keil MDK-ARM，ARMCC V5.06 |
| 固件框架 | STM32Cube FW_H7 V1.13.0 |

## 运行架构

程序启动后完成时钟、GPIO、DMA、串口、定时器和编码器初始化，然后创建四个 FreeRTOS 任务。

| 任务 | 优先级 | 周期 | 主要工作 |
| --- | --- | --- | --- |
| `motorTask` | High | 1 毫秒 | 更新云台轨迹，执行梯形规划和圆形轨迹 |
| `commandTask` | Normal | 1 毫秒轮询 | 处理两路串口协议，发送状态和波形 |
| `imuTask` | Normal | 2 毫秒 | 读取陀螺仪数据，更新航向和角速度 |
| `defaultTask` | Normal | 100 毫秒 | 读取云台编码器，校准角度零点 |

控制逻辑分为三条链路。

- 底盘速度环：TIM6 每 1 毫秒中断一次，每 20 次读取编码器转速，经 PID 输出 PWM 给四个车轮。
- 云台位置环：TIM15 以 50kHz 产生中断，按 DDS 方式输出步进脉冲，`motorTask` 每毫秒更新速度和方向。
- 航向修正：底盘直行时锁定陀螺仪航向，转向时跟踪角速度，修正量叠加到左右两侧轮速。

## 串口与协议

| 串口 | 引脚 | 波特率 | 用途 |
| --- | --- | --- | --- |
| USART1 | PA9 TX，PA10 RX | 115200 8N1 | 手动控制，二进制和文本命令 |
| USART3 | PD8 TX，PD9 RX | 115200 8N1 | 陀螺仪数据 |
| UART5 | PC12 TX | 115200 | 波形输出，单线半双工 |
| UART8 | PE0 RX，PE1 TX | 115200 8N1 | ROS 2 主控 |

### ROS 2 底盘协议

UART8 使用二进制帧，接收和发送格式一致。

```
帧头 0xAA | 命令 1 字节 | 长度 1 字节 | 数据 N 字节 | 校验 1 字节
校验值等于命令、长度和数据逐字节相加后的低 8 位
```

| 命令 | 值 | 数据 | 说明 |
| --- | --- | --- | --- |
| 四轮转速 | 0x10 | 4 个 int16，小端，单位 RPM | 顺序为左前、右前、左后、右后，范围正负 250 |
| 停止 | 0x22 | 无 | 四轮停机并清空 PID |
| 遥测 | 0x35 | 36 字节 | 由底盘协议模块每 20 毫秒主动发送 |

遥测数据包含时间戳、四轮累计脉冲、四轮实测转速、偏航角、偏航角速度、状态标志和堵转次数。偏航角与角速度按 0.1 度放大后以 int16 发送。

安全机制包括三项。

- 命令超时：超过 300 毫秒未收到新命令时自动停机。
- 堵转保护：至少两个车轮指令转速不低于 20RPM 而实测不超过 3RPM，持续 450 毫秒后停机。
- 堵转恢复：先发送零速命令，并在 1 秒冷却后重新下发运动命令。

### 手动控制协议

USART1 同时支持二进制帧和文本命令。文本命令以回车或换行结尾，命令名不区分大小写。

| 命令 | 示例 | 说明 |
| --- | --- | --- |
| `PAN 角度` | `PAN 90` | 水平轴转到指定角度，可追加冒号分隔的速度 |
| `TILT 角度` | `TILT 20` | 俯仰轴转到指定角度，范围为负 45 到正 45 度 |
| `SPINP 速度` | `SPINP 20` | 水平轴连续转动，单位 度每秒 |
| `SPINT 速度` | `SPINT -10` | 俯仰轴连续转动，单位 度每秒 |
| `MOVE 角度` | `MOVE 90` | 按指定角度方向持续转动 |
| `MOVE 角度:距离:速度` | `MOVE 90:30:20` | 按角度和距离移动云台，距离和速度需同时给出 |
| `CIRCLE 半径` | `CIRCLE 20` | 云台画圆，半径小于 1 时停止 |
| `HOME` | `HOME` | 两轴回到零度 |
| `ZERO` | `ZERO` | 将当前编码器位置设为零点 |
| `STOP` | `STOP` | 停止云台和底盘 |
| `M 转速1 转速2 转速3 转速4` | `M 100 100 100 100` | 直接设置四轮转速，单位 RPM |
| `Y 角度` | `Y 0` | 设置目标航向 |
| `STATUS` | `STATUS` | 查询云台角度和运动状态 |
| `IMU` | `IMU` | 查询偏航角和角速度 |
| `RAW` | `RAW` | 查询编码器原始值 |
| `SCAN` | `SCAN` | 扫描 I2C1 设备地址 |
| `SCAN2` | `SCAN2` | 扫描 I2C2 设备地址 |
| `MON` | `MON` | 开关周期状态输出 |
| `PING` | `PING` | 返回 PONG |
| `HELP` | `HELP` | 输出命令摘要 |

二进制命令使用相同帧格式，命令码包括 0x01 到 0x04 控制云台，0x10 到 0x12 控制底盘和航向，0x20 到 0x23 执行回零、置零、停止和画圆，0x30 到 0x34 查询状态，0x40 和 0x41 控制连续转动。

## 引脚分配

### 底盘电机

| 车轮 | PWM | 方向 1 | 方向 2 | 编码器定时器 | 编码器引脚 |
| --- | --- | --- | --- | --- | --- |
| 左前 | PC6 | PC0 | PC1 | TIM2 | PA15，PB3 |
| 右前 | PC7 | PC3 | PC2 | TIM3 | PB4，PB5 |
| 左后 | PC8 | PA11 | PA12 | TIM4 | PD12，PD13 |
| 右后 | PC9 | PB12 | PB13 | TIM1 | PE9，PE11 |

右前轮方向引脚在代码中交换，用于修正正转方向。

### 云台步进驱动

| 功能 | 水平轴 | 俯仰轴 |
| --- | --- | --- |
| DIR | PB0 | PD0 |
| STEP | PB1 | PD1 |
| EN | PA0 | PD2 |
| MS1 | PA2 | PD3 |
| MS2 | PA3 | PD4 |
| MS3 | PA4 | PD5 |
| SLEEP | PA5 | PD6 |
| RESET | PA6 | PD7 |

两个轴都使用 16 细分，也就是每圈 3200 步。EN 为低电平时驱动使能。

### 编码器与定时器

| 功能 | 资源 | 说明 |
| --- | --- | --- |
| 水平轴编码器 | I2C1，PB8 SCL，PB7 SDA | 地址 0x06 |
| 俯仰轴编码器 | I2C2，PB10 SCL，PB11 SDA | 地址 0x06 |
| 步进脉冲 | TIM15 | 预分频 47，周期 99，中断频率 50kHz |
| 车轮 PWM | TIM8 | 预分频 239，周期 99，频率 20kHz |
| 系统时基 | TIM6 | 1kHz |
| 车轮编码器 | TIM1 到 TIM4 | 四倍频计数 |

## 云台控制参数

| 参数 | 水平轴 | 俯仰轴 |
| --- | --- | --- |
| 减速比 | 6 比 1 | 3.2 比 1 |
| 每度步数 | 53.33 | 28.44 |
| 角度范围 | 无软件限位 | 负 45 到正 45 度 |
| 默认速度 | 50 度每秒 | 30 度每秒 |
| 最大速度 | 100 度每秒 | 100 度每秒 |

公共运动参数位于 `config.h`。

- 最大速度 15000 步每秒。
- 加速度 300000 步每秒平方。
- 到位死区 3 步。
- 航向环和角速度环参数位于 `main.h`，例如 `YAW_KP` 和 `OMEGA_KP`。

## 构建与烧录

1. 用 STM32CubeMX 打开 `H743VIT6.ioc`，确认外设配置后生成代码。
2. 用 Keil MDK-ARM 打开 `MDK-ARM/H743VIT6.uvprojx`。
3. 编译工程，生成 `MDK-ARM/H743VIT6/H743VIT6.hex`。
4. 连接调试器后下载固件。

应用层源码已经加入 Keil 工程的 EricE 分组，不需要手动添加文件。工程使用 ARMCC V5.06，切换编译器前应先确认 HAL 和 FreeRTOS 的兼容性。

## 调试建议

1. 上电后先确认 USART1 能输出启动信息。
2. 发送 `PING`，确认串口收发正常。
3. 发送 `SCAN` 和 `SCAN2`，确认两路编码器都能被识别。
4. 发送 `RAW`，检查编码器原始值是否随转动变化。
5. 发送 `PAN 30` 和 `TILT 10`，观察云台动作和角度反馈。
6. 用 ROS 2 主控下发四轮转速，确认遥测中的实测转速跟随目标。
7. 航向控制异常时，先检查陀螺仪串口是否有数据，再调整航向参数。

## 已知问题

- 底盘四轮采用直接转速控制，`mecanum.c` 目前只用于偏航角速度估算，不参与轮速分配。
- 俯仰轴为开环步进控制，没有闭环位置校正，长时间运行可能累积误差。
- `servo_feedback.c` 已提供接口，但主程序没有创建对应任务，当前版本不会主动发送云台反馈帧。
- 工程依赖 ARMCC V5.06，较新的 Keil 版本需要先确认编译器可用。
- 旧版 README 只描述二轴云台，与当前四轮底盘功能不一致，本文件已按现有代码重写。
